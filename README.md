# 🎰 Random Name Selector

A cinematic, production-quality **Random Name Picker** web application built with pure HTML, CSS, and JavaScript — no frameworks.

Designed to feel like a live TV lottery draw or award show, optimized for classroom projectors and large displays.

## ✨ Features

- **Cinematic draw experience** — 6-second suspense sequence with countdown, slot-machine spin, and dramatic reveal
- **Futuristic dark cyber theme** — Glassmorphism panels, neon glow accents, animated gradient background
- **Dancing Cyber Mascot** — Animated character with idle, dancing, and victory states
- **Manage Names** — Add/remove names individually or in bulk (CSV/newline), persisted in localStorage
- **Non-repeating draws** — Tracks remaining names across sessions
- **Particle & light beam backgrounds** — Dual-canvas animation engine
- **Victory celebrations** — Confetti, fireworks, golden flash, and shockwave effects
- **Sound synthesis** — Built-in Web Audio API effects (no external files needed)
- **Fully responsive** — Works on any screen size

## 🚀 Usage

1. Open `index.html` in any modern browser
2. Click **Manage Names** to add your list of names
3. Click **START DRAW** and enjoy the show!

## 🛠 Tech Stack

- HTML5
- CSS3 (Vanilla — no Tailwind/Bootstrap)
- JavaScript (ES6+)
- Google Fonts (Poppins)
- Web Audio API
- Canvas API
- localStorage for persistence
